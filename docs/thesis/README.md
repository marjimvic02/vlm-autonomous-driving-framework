# Master's thesis

The [full thesis](TFM_Victor.pdf), dated July 6, 2026, is the academic reference for this project:

> Víctor Marín Jiménez. *VLM-based high-level action planner for mobile robots*. Master's Thesis, MSc in Automatic Control and Robotics (MUAR), Universitat Politècnica de Catalunya, 2026. Supervisor: Vicenç Puig Cayuela.

The document covers motivation, related work, architecture, experimental methodology, results, discussion, conclusions and future work. The repository README provides a brief introduction; the installation and architecture guides describe the current code, including portability and validation corrections made after the evaluated runs.

| Architecture and methodology | Chapter 3 |
| Results and study limitations | Chapter 4; Table 12 for aggregates |
| Discussion and framework limitations | Chapter 5 |
| Conclusions and extensions | Chapters 8 and 9 |
